## 模板1: 查询功能

### 场景询问清单

```markdown
## 查询功能询问框架

### 查询条件
- 有哪些查询条件？
- 每个条件的查询方式？
  - [ ] 模糊查询（如：名称包含XX）
  - [ ] 精确查询（如：编码等于XX）
  - [ ] 范围查询（如：日期在XX到XX之间）
  - [ ] 下拉选择（如：状态等于XX）
- 查询条件为空时，显示什么？
  - [ ] 显示全部数据
  - [ ] 提示"请输入查询条件"
  - [ ] 显示空列表

### 查询结果
- 查询结果包含哪些字段？
- 默认排序规则？（按XX升序/降序）
- 分页规则？（每页多少条？默认第几页？）
- 是否支持导出？

### 交互
- 查询按钮在哪里？
- 重置按钮在哪里？
- 是否需要"展开/收起"更多查询条件？
```

### 模板示例

```markdown
### 1. 查询功能

**查询条件：**
| 字段名 | 控件类型 | 查询方式 | 说明 |
|--------|---------|---------|------|
| 文件类型名称 | 文本框 | 模糊查询 | 支持模糊匹配 |
| 物料类别 | 下拉框 | 精确查询 | 必选 |
| 状态 | 下拉框 | 精确查询 | 全部/启用/禁用 |

**查询规则：**
- 查询条件非必填，查询条件置空进行查询时展示系统内全量数据
- 查询结果按文件类型编码升序展示
- 默认每页显示20条，支持分页

**查询结果：**
| 字段名 | 说明 |
|--------|------|
| 文件类型编码 | 唯一标识 |
| 文件类型名称 | 显示名称 |
| 物料类别 | 关联显示 |
| 状态 | 启用/禁用 |
| 操作 | 编辑/删除 |
```

## 模板2: 新增功能

### 场景询问清单

```markdown
## 新增功能询问框架

### 必填字段
- 需要填写哪些字段？
- 哪些字段是必填的？
- 是否有自动生成的字段？（编码、日期）
- 是否需要验重？哪些字段需要验重？

### 值列表
- 哪些字段有值列表？
  - 取哪个表？
  - 取哪个快码？
  - 级联关系？
- 是否支持搜索？
- 单值是否默认带出？

### 保存逻辑
- 保存前需要校验什么？
- 保存后跳转到哪里？
  - [ ] 返回列表（刷新列表）
  - [ ] 留在当前页面（继续新增）
  - [ ] 跳转到编辑页面
- 保存成功/失败的提示？
```

### 模板示例

```markdown
### 2. 新增功能

**必填字段：**
| 字段名 | 控件类型 | 必填 | 说明 |
|--------|---------|------|------|
| 文件类型编码 | 文本框 | 是 | 自动生成，格式：物料类别代码+3位流水号 |
| 文件类型名称 | 文本框 | 是 | 最多50字符 |
| 物料类别 | 下拉框 | 是 | 级联实体类型 |
| 文件类型 | 下拉框 | 是 | 取快码XX |
| 分类要素 | 下拉框 | 是 | 取快码XX |
| 状态 | 开关 | 是 | 默认启用 |

**值列表说明：**
- **物料类别**：取快码Item_Categories，支持搜索
- **文件类型**：级联物料类别，取所选物料类别下的文件类型
- **分类要素**：级联物料类别，取所选物料类别下的分类要素

**保存逻辑：**
1. 保存时校验文件类型名称不允许重复
2. 校验失败，报错："当前文件类型名称已存在，请重新命名"
3. 校验通过，保存数据，自动生成编码
4. 保存成功，弹出提示，返回列表并刷新
```

## 模板3: 编辑功能

### 场景询问清单

```markdown
## 编辑功能询问框架

### 可编辑字段
- 哪些字段可以编辑？
- 哪些字段不可编辑？（编码类通常不可编辑）
- 编辑后是否需要审核？

### 状态变更
- 状态类字段编辑后是否影响其他数据？
- 失效时是否级联失效子数据？

### 保存逻辑
- 保存前需要校验什么？
- 保存后跳转/提示？
```

### 模板示例

```markdown
### 3. 编辑功能

**可编辑字段：**
| 字段名 | 可编辑 | 不可编辑原因 |
|--------|--------|-------------|
| 文件类型名称 | ✅ | - |
| 物料类别 | ❌ | 已使用，修改会影响关联数据 |
| 文件类型 | ✅ | - |
| 分类要素 | ✅ | - |
| 状态 | ✅ | - |
| 失效日期 | ✅ | - |

**编辑限制：**
- 文件类型编码不可编辑
- 物料类别不可编辑（已使用）
- 修改物料类别会同步修改关联的链路信息

**状态变更逻辑：**
- 失效时，同步将文件类型下的文件类型分类及文件类型分类下的关键字段失效
- 启用时，不级联启用下级数据
```

## 模板4: 删除功能

### 场景询问清单

```markdown
## 删除功能询问框架

### 删除类型
- [ ] 物理删除（数据永久删除）
- [ ] 逻辑删除（标记为无效）

### 依赖检查
- 删除前需要检查什么？
- 在哪些表中被引用？
- 如果被引用，如何处理？
  - [ ] 报错，不允许删除
  - [ ] 提示，但允许删除

### 确认提示
- 是否需要确认弹窗？
- 确认消息内容？
```

### 模板示例

```markdown
### 4. 删除功能

**删除类型：** 逻辑删除（标记为禁用）

**删除逻辑：**
1. 删除前进行检查，检查当前文件类型在链路定义、地图配置中是否被引用
2. 若已被引用，报错不允许删除
   - 报错消息："当前数据已被使用，不允许删除，请失效当前数据或调整其他配置后删除"
3. 若其他关联功能未使用，弹出确认窗口
   - 弹窗消息："删除后无法恢复，是否确认删除"
4. 用户确认后，执行删除操作
5. 删除成功，弹出提示，刷新列表
```

### 模板示例

```markdown
### 5. 导出功能

**导出范围：** 当前查询结果

**导出格式：** Excel (.xlsx)

**导出字段：** 用户选择字段（默认全选）

**导出规则：**
1. 点击导出按钮，弹出字段选择弹窗
2. 用户选择要导出的字段（默认全选）

**大数据量处理：**
- 导出数据量>10000条时，提示用户"数据量较大，请耐心等待"
- 导出过程显示进度条
```

```markdown
### 6. 上传功能

**文件限制：**
| 类型 | 限制 |
|------|------|

- 上传文件存储到文件服务器
```

## 模板9: 追溯谱系与召回

### 场景询问清单

```markdown
## 追溯谱系与召回询问框架

### 追溯粒度与对象
- 追溯对象是什么？（原材料/在制/成品/序列号）
- 粒度是什么？（批次/箱/件/序列号）
- 需要支持正向追溯、反向追溯，还是两者？

### 谱系关系口径
- 是否存在拆分/合并/返工/报废/转产？
- 多对多关系如何记录数量分摊？（质量平衡/单位换算）
- 允许修改谱系关系吗？如何更正与留痕？

### 召回/演练
- 触发输入是什么？（原材料批次/成品批次/序列号/供应商批次）
- 影响范围要覆盖哪些状态？（在制/库存/在途/已出货）
- 目标时限是多少？（例如 X 分钟内出具全量清单）
- 需要导出哪些证据？（谱系图、出货清单、库存清单、检验记录、操作留痕）

### 审计与权限
- 哪些操作必须留痕？（修改主数据/更正/补打标签/冻结解冻）
- 权限如何分离？（录入/审批/放行/更正）

### 集成与采集
- 数据来自哪些系统？（ERP/MES/WMS/QMS）
- 现场采集点位有哪些？（入库/领料/工序/包装/出库）
- 离线/弱网如何处理？（缓存补传、冲突处理）
```

### 模板示例

```markdown
### 9. 追溯谱系与召回

**追溯粒度：** 成品批次 + 箱码
**追溯范围：** 正向 + 反向

**谱系关系：**
- 支持拆分/合并：是
- 数量口径：按净重（kg）分摊，单位换算来源为物料主数据
- 更正机制：仅允许追加更正单据，禁止覆盖；全量留痕（前后值+原因+审批）

**反向追溯输出（成品 → 输入）：**
- 输入：FGLOT-20260330-01
- 输出：原材料批次清单、工序记录、检验记录、包装记录
- 时限：5 分钟内出具
- 证据包：Excel + PDF（含查询条件、口径说明、操作留痕）

**正向追溯输出（输入 → 影响成品）：**
- 输入：RMLOT-20260301-08
- 输出：影响的在制/库存/已出货清单
- 处置动作：支持冻结库存、生成召回通知清单

**召回演练：**
- 退出标准：清单覆盖率 100%，口径一致，证据包可复核
```

## 模板10: 数据项规范

本模板规定数据项表格的标准格式，适用于所有功能设计文档中的详细设计章节。

### 标准列格式（12列，不可缩减）

```markdown
| 序号 | 字段名 | 控件类型 | 数值类型 | 长度 | 必输 Y/N | 新增 Y/N | 编辑 Y/N | 值列表说明 | 默认值 | 校验规则 | 其他说明 |
|------|--------|---------|---------|------|---------|---------|---------|-----------|-------|---------|---------|
| 1    | 字段A  | 文本    | 字符    | 200  | Y       | Y       | N       | -         | -     | 不能为空 | 创建后只读 |
| 2    | 字段B  | 下拉    | 字符    | 50   | Y       | Y       | Y       | 启用/禁用  | 启用  | 不能为空 | -       |
```

### 数值类型命名规范（中文）

| 数据库类型 | PRD写法 | 长度列 | 附加说明 |
|-----------|--------|-------|---------|
| VARCHAR / NVARCHAR | 字符 | 必填，如 200 | - |
| INT | 整数 | - | 注明范围，如（≥0） |
| DECIMAL | 小数 | 精度说明 | 如（保留2位小数） |
| DATE | 日期 | - | 注明格式，如（YYYY-MM-DD） |
| DATETIME | 日期时间 | - | 注明格式，如（YYYY-MM-DD HH:mm:ss） |
| BOOLEAN / TINYINT(1) | 布尔 | - | 值列表写"是/否" |
| TEXT | 长文本 | 可选 | 无长度限制时可写"-" |

### 新增 Y/N、编辑 Y/N 填写规则

| 页面类型 | 新增 Y/N | 编辑 Y/N | 备注 |
|---------|---------|---------|------|
| 只读详情页 | N | N | - |

**评分维度（5维度各20分，满分100）：**
